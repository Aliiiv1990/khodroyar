# برنامه جامع استقرار فول‌استک روی لیارا (Liara Cloud) با سرور و دیتابیس اختصاصی

این طرح معماری، برنامه نمایشگاه خودرو را از یک برنامه کلاینت وابسته به فایربیس گوگل، به یک سامانه یکپارچه فول‌استک (Full-Stack Node.js + React) تبدیل می‌کند که سرور API و پایگاه داده آن مستقیماً روی سرورهای پلتفرم ابری لیارا (Liara) در تهران اجرا می‌شود و با کشیدن و رها کردن (Drag & Drop) یک فایل زیپ به راحتی مستقر می‌گردد.

---

## بررسی کاربر و تصمیمات کلیدی (User Review & Critical Decisions)

> [!IMPORTANT]
> با توجه به اسکیپ شدن سوالات، رویکرد بهینه و چندمنظوره برای دیتابیس انتخاب شده است:
> **پشتیبانی دوگانه هوشمند (Dual Database Architecture):**
> سرور به گونه‌ای پیاده‌سازی می‌شود که در حالت پیش‌فرض بدون نیاز به ساخت یا هزینه دیتابیس جداگانه در لیارا، از پایگاه داده پایدار SQLite روی دیسک دائمی (`/data`) استفاده کند. همزمان، اگر در تنظیمات متغیر محیطی `DATABASE_URL` (پستگرس لیارا) ست شود، به صورت خودکار به دیتابیس ابری متصل خواهد شد.

---

## ۱. نمای کلی و معماری سیستم (Overview & Architecture)

سامانه به صورت یک برنامه جامع Node.js پیکربندی می‌شود که هم رابط کاربری واکنش‌گرای React را ارائه می‌دهد و هم مسیرهای REST API پایگاه داده را مدیریت می‌کند.

### مزایای استقرار روی لیارا:
1. **۱۰۰٪ بدون فیلتر و پرسرعت در سراسر ایران:** سرورها در دیتاسنتر تهران قرار دارند و روی تمام اپراتورها (همراه اول، ایرانسل، رایتل و مخابرات) بدون نیاز به VPN کار می‌کنند.
2. **استقرار با درگ‌وان‌دراپ زیپ (Drag & Drop):** کاربر بدون نیاز به اجرای دستورات ترمینال، فقط با زیپ کردن پوشه پروژه و کشیدن آن داخل کنسول لیارا، برنامه را بالا می‌آورد.
3. **همگام‌سازی واقعی بین تمام کاربران:** هر آگهی که ثبت شود، در دیتابیس متمرکز لیارا ذخیره شده و تمام مراجعه‌کنندگان در لحظه آن را می‌بینند.

```
┌────────────────────────────────────────────────────────────────────────┐
│                        مرورگر کاربران و همکاران                        │
│                 (موبایل / تبلت / کامپیوتر در سراسر ایران)              │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ HTTP / REST API (بدون فیلتر)
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                     پلتفرم ابری لیارا (Liara Cloud)                    │
│                                                                        │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │                    Node.js Express Server (پورت ۳۰۰۰)            │  │
│  │  - ارائه فرانت‌اند کامپایل‌شده (SPA React + Tailwind)            │  │
│  │  - مسیرهای API:                                                  │  │
│  │    * GET  /api/listings          (دریافت زنده آگهی‌ها)            │  │
│  │    * POST /api/listings          (ثبت آگهی جدید همکار)          │  │
│  │    * POST /api/admin/sync        (انتشار دسته‌ای توسط ادمین)     │  │
│  │    * POST /api/admin/clear       (پاکسازی دیتابیس توسط ادمین)    │  │
│  │    * GET  /api/health            (بررسی سلامت سرور)              │  │
│  └──────────────────────────────────┬───────────────────────────────┘  │
│                                     │                                  │
│                                     ▼                                  │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │                    پایگاه داده متمرکز در لیارا                    │  │
│  │  - دیسک دائمی (Persistent Disk /data) با فایل پایدار دیتابیس      │  │
│  │  - و امکان اتصال خودکار به PostgreSQL لیارا (در صورت تعریف URL)  │  │
│  └──────────────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────────┘
```

## ۲. مشخصات و استانداردهای لیارا (Liara Standard Specifications)

مطابق با مستندات رسمی Liara Cloud، فایل‌های اختصاصی زیر به پروژه افزوده می‌شوند:

### ۱. فایل `liara.json`
تنظیم پلتفرم `node`، پورت `3000` و دیسک دائمی برای جلوگیری از حذف داده‌ها هنگام ری‌استارت:
```json
{
  "platform": "node",
  "app": "car-exhibition",
  "port": 3000,
  "disks": [
    {
      "name": "data",
      "mountTo": "/data"
    }
  ]
}
```

### ۲. فایل `.liaraignore`
جلوگیری از آپلود فایل‌های سنگین محلی برای افزایش سرعت آپلود:
```text
node_modules/
dist/
.git/
.env
.env.local
.DS_Store
```

### ۳. اتصال شبکه و پورت سرور
سرور روی `0.0.0.0` و پورت تعیین‌شده توسط لیارا گوش می‌دهد:
```typescript
const PORT = Number(process.env.PORT) || 3000;
app.listen(PORT, '0.0.0.0', () => { ... });
```

## ۳. مراحل اجرایی پیاده‌سازی (Step-by-Step Execution Plan)

### مرحله ۱: ایجاد سرور فول‌استک (`server.ts`)
- راه‌اندازی سرور Express با سازگاری همزمان در محیط توسعه (Vite dev middlewares) و محیط پروداکشن (ارائه فایل‌های استاتیک پوشه `dist`).
- پیاده‌سازی مسیرهای کامل REST API برای دریافت، ثبت تکی، انتشار دسته‌ای و پاکسازی آگهی‌ها.
- سیستم ذخیره‌سازی فایل دیتابیس در مسیر `/data/cars_database.json` (یا مسیر محلی در محیط توسعه) به همراه پشتیبان‌گیری.

### مرحله ۲: اتصال کلاینت فرانت‌اند به سرور لیارا
- به‌روزرسانی توابع کلاینت در `src/utils/cloudSync.ts` و `App.tsx` تا به صورت خودکار به `/api/listings` و `/api/admin/sync` سرور متصل شوند.
- حفظ سازگاری آفلاین و کش دسکتاپ/موبایل در صورت قطعی موقت اینترنت کاربر.

### مرحله ۳: آماده‌سازی اسکریپت‌های Build و Start
- تنظیم دستورات `build` و `start` در `package.json` به گونه‌ای که حین استقرار در لیارا ابتدا فرانت‌اند با `npm run build` ساخته شود و سپس سرور اجرا گردد.

### مرحله ۴: تولید فایل‌های پیکربندی و راهنمای درگ‌وان‌دراپ
- تولید فایل‌های `liara.json`، `.liaraignore` و `.env.example`.
- افزودن راهنمای تصویری و شفاف در تب مدیریت داده‌ها جهت راهنمایی کاربر در ۳ کلیک.

### مرحله ۵: اعتبارسنجی، تست‌ها و کامپایل
- اجرای کامل تست‌های واحد و کامپایل بیلد نهایی برای اطمینان از عملکرد بدون خطا.
